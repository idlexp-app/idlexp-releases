# IdleXP

Quatro contas do Huntera em uma janela só, com modo economia.

## Baixar

**[Baixar o IdleXP para Windows](https://github.com/idlexp-app/idlexp-releases/releases/latest/download/IdleXP-Setup.exe)**

Este link sempre entrega a versão mais nova. Depois de instalado, o IdleXP se atualiza sozinho ao abrir.

## Na primeira vez

O instalador ainda não tem assinatura digital, então o Windows mostra o aviso azul
"O Windows protegeu o computador". Clique em **Mais informações** e depois em
**Executar assim mesmo**.

- Só Windows 64 bits.
- Instala só para o seu usuário e não pede administrador.
- Desinstalar não apaga os logins das contas.

Este repositório guarda só os instaladores. O IdleXP não é afiliado ao Huntera.
